## 🎓 Key Decisions Made

### 1. Cron Jobs
**Decision:** Disabled cron jobs for Hobby plan compatibility
**Trade-off:** Automatic payment deadline checks won't run
**Solution:** Can upgrade to Vercel Pro ($20/month) or use external service
**Impact:** Manual testing possible via curl, but production needs Pro or external service
**When to revisit:** After budget approved for Pro upgrade

### 2. Deployment Method
**Decision:** Used Vercel CLI for manual deployment instead of waiting for auto-deploy
**Reason:** Auto-deploy webhook wasn't triggering from GitHub
**Benefit:** Faster feedback, confirmed deployment works
**Note:** Future pushes may auto-deploy if webhook is fixed

### 3. Environment Variables
**Decision:** Kept CRON_SECRET in .env.local, removed from vercel.json
**Reason:** Can be added to Vercel dashboard later if needed
**Impact:** Clean config, easier to manage secrets separately
